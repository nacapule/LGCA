# Alpha follow-up: cluster density

Open [the comparison](index.html). 60 runs: alpha .75/.80/.85/.90, sizes90/120/180, five seeds, sensitivity6, density input.4. All runs reach80,000 steps.

The primary measurement is cluster mass/area, averaged over the last quarter of each selected observation horizon. Alpha.80 shows a strong size trend; alpha.90 is much less dense but still has a size effect and seed-dependent evolution. No critical alpha or thermodynamic condensation boundary is established.
